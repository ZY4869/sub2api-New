## 撤销本批次，保留上游 v0.2.13

先保存尚未提交的工作，确认 `git status --short` 无输出；不要使用 reset、clean 或强制推送清理当前工作。以下命令在仓库根目录执行，先同步 main，再生成一条撤销提交：

```powershell
git fetch origin --tags
git switch main
git pull --ff-only origin main
git revert --no-commit rollback/before-local-20261003-002413..snapshot/local-20261003-002413
git diff --cached --stat
git commit -m "revert: roll back local snapshot from 2026-10-03"
git push origin main
```

每条命令成功后再执行下一条。提交前检查暂存 Diff 确实只撤销这一批更改，按当时版本运行相关测试。没有后续代码修改时，撤销后的 Git 树应与回退标签完全一致，可以在 commit 前检查：

```powershell
git diff --cached --exit-code rollback/before-local-20261003-002413
```

如果后续又修改了相同代码，revert 可能出现冲突；这时停止后续命令，逐项保留后续需要的逻辑，或在冲突阶段执行 `git revert --abort` 退出撤销流程。后续新增功能存在时，不应要求整个仓库与旧基线完全相同。

撤销操作会同时移除本批次新增的说明文件，但文件仍可以从 snapshot 标签或 Git 历史读取。撤销不删除这两个标签，也不改写共享分支历史。
